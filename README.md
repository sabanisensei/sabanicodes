## ✨ About

Welcome to Sabanicodes — a personal repository for building small, useful, and sometimes playful things with code. This space is for experimenting, learning, and sharing projects that may start as quick prototypes and grow into something bigger.

---

## 🛠️ Tech Stack

This repository is intentionally flexible. It can include a mix of languages and tools such as:

- Python
- JavaScript / TypeScript
- Bash / Shell
- Node.js
- HTML / CSS
- Rust, Go, or other experiments

---

## 📦 Contributing

Contributions are welcome.

- Open an issue to suggest a new idea
- Submit a pull request with improvements or new projects
- Keep changes focused and well-documented

A good project folder should usually include:

- a clear purpose
- instructions to run it
- a short explanation of dependencies
- a README if needed
